- **API `lang` parameter** — API routes accept `lang=en|es|vi` (default `en`). Unknown values fall back to `en`. Example: `GET /api/forecast?lang=vi`.
- **Translation is best-effort** — Web-searched content (factor explanations, solutions) is translated through the Kilo AI Gateway and cached. If translation fails or is unavailable, the English original is returned. Numeric values are preserved, and translations that change numbers are rejected. **NEW: Factor names and categories are also translated at response time** — factor `name` (title) and `category` fields are included in the `translateStructured` keys for `/api/dynamic-factors` and `/api/regional-factors`, so switching the UI language instantly updates factor titles and categories across all UI surfaces.
